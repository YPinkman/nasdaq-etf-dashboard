# 159941 纳指ETF监控面板

本地运行的 React + TypeScript 数据看板，用于观察场内纳指 ETF 的交易状态。

当前版本通过本地 Vite 代理读取东方财富行情和 HaoETF 实时估值；请求失败时直接提示未获取到数据。不自动交易，不下单。

## 本地运行

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 4173
```

打开 Vite 输出的本地地址。

## 常用命令

```bash
npm test
npm run lint
npm run build
```

## 数据入口

- 行情数据源：`src/services/marketData.ts`
  - 东方财富：场内价格、ETF 涨跌幅、纳指期货涨跌幅
  - HaoETF：实时估值，用于页面 IOPV/溢价率计算
- 本地持仓账本：`src/lib/portfolioBook.ts`
- 计算与判断逻辑：`src/lib/calculations.ts`

## 持仓与手续费

- 支持录入加仓买入、减仓卖出、成交均价和每笔手续费。
- 买入手续费计入当前持仓成本。
- 卖出手续费从卖出收入中扣除，并计入已实现盈亏。
- 首页展示全部标的总持仓；进入单只标的详情后维护该标的交易流水。
- 场内 ETF 二级市场交易佣金以个人券商账户实际费率为准，本工具不自动抓取个人佣金标准。
